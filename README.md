#  Water Potability Analysis

This project focuses on analyzing the **Water Potability Dataset** from Kaggle to explore the quality and drinkability of water samples based on various chemical properties. The goal was to perform **data cleaning, analysis, and visualization** using Python and its popular data science libraries.

---

##  Dataset Overview

The dataset includes the following features:

- `ph` — pH value of water.
- `Hardness` — the amount of dissolved calcium and magnesium.
- `Solids` — total dissolved solids in ppm.
- `Chloramines` — amount of chloramines in ppm.
- `Sulfate` — sulfate concentration in mg/L.
- `Conductivity` — electrical conductivity of water.
- `Organic_carbon` — organic carbon concentration.
- `Trihalomethanes` — trihalomethanes concentration in μg/L.
- `Turbidity` — measure of light scattering due to particles.
- `Potability` — indicates if water is safe to drink (1 = Potable, 0 = Not Potable).

##  Project Workflow

1. **Data Cleaning**
   - Handled missing values.
   - Checked and treated outliers.
   - Verified data types.

2. **Exploratory Data Analysis (EDA)**
   - Statistical summary and distribution checks.
   - Visualization of feature relationships.
   - Correlation heatmaps.

3. **Insights**
   - Identified key factors affecting water potability.
   - Discovered patterns and distributions using data visualization.

---

## 📌 Conclusion

The analysis highlights the importance of chemical attributes such as pH, sulfate, and trihalomethanes in determining water safety. Visualizations made it clear how each feature is distributed and how it influences the potability of water.
